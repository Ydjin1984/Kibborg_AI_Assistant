# ТЗ для Claude

Изучи текущий проект и реализуй модуль Browser Agent для локального ИИ.

Цель:
Локальная LLM должна получить полноценный доступ к открытому браузеру Google Chrome через Chrome DevTools Protocol (CDP) и Playwright.

Требования:

## Подключение к браузеру

* Подключение к уже запущенному Chrome через:
  --remote-debugging-port=9222

* Использовать:

  * Playwright
  * Chrome DevTools Protocol (CDP)

* Агент должен работать с уже открытыми вкладками.

* Не запускать новый браузер без необходимости.

---

## Работа с DOM

Агент должен иметь возможность:

* Читать DOM дерево страницы.
* Получать HTML любого элемента.
* Получать текст любого элемента.
* Получать атрибуты элементов.
* Получать ссылки.
* Получать изображения.
* Получать таблицы.
* Получать JSON данные.
* Получать данные из localStorage.
* Получать данные из sessionStorage.
* Получать Cookies.
* Получать Network Responses.
* Получать данные WebSocket соединений.
* Получать данные XHR и Fetch запросов.

Важно:

Основной источник информации — DOM и сетевые данные.

Не использовать OCR и скриншоты если пользователь явно не запросил визуальный анализ.

---

## Интеллектуальный парсинг

Агент должен уметь:

* Анализировать структуру сайта.

* Находить нужные данные по смыслу.

* Извлекать:

  * цены
  * таблицы
  * формы
  * карточки товаров
  * новости
  * графики
  * текстовый контент

* Автоматически преобразовывать данные в:

  * JSON
  * CSV
  * DataFrame
  * Markdown

---

## Управление браузером

Агент должен иметь возможность:

* Открывать страницы.
* Закрывать страницы.
* Переключаться между вкладками.
* Нажимать кнопки.
* Заполнять формы.
* Вводить текст.
* Копировать данные.
* Вставлять данные.
* Выделять текст.
* Прокручивать страницу.
* Загружать файлы.
* Скачивать файлы.
* Перетаскивать элементы.
* Выбирать значения в списках.
* Отправлять формы.

---

## Скриншоты

Скриншоты использовать только по запросу пользователя.

Если пользователь просит:

* проанализировать график
* распознать изображение
* проверить визуальное состояние страницы

тогда использовать:

page.screenshot()

или

locator.screenshot()

Во всех остальных случаях работать через DOM и сетевые данные.

---

## Клонирование сайтов

Реализовать функцию Website Cloner.

Возможности:

* Скачать HTML.
* Скачать CSS.
* Скачать JS.
* Скачать изображения.
* Скачать шрифты.
* Скачать SVG.
* Скачать видео.
* Скачать JSON запросы.

Сохранять структуру директорий.

Конвертировать абсолютные ссылки в локальные.

Результат:

Полностью работающая локальная копия сайта для офлайн просмотра.

## Архитектура

Создать отдельный Browser Service.

Структура:

browser/
├── browser_manager.py
├── cdp_client.py
├── page_controller.py
├── dom_parser.py
├── network_monitor.py
├── website_cloner.py
├── screenshot_service.py
├── tools.py
└── schemas.py

## Tool Calling

Каждую возможность оформить как отдельный Tool.

Примеры:

open_url()

click_element()

type_text()

extract_table()

extract_links()

extract_json()

download_file()

clone_website()

capture_screenshot()

analyze_dom()

get_network_requests()

get_websocket_messages()

---

## Результат

После реализации агент должен уметь самостоятельно:

1. Анализировать любую открытую страницу.
2. Извлекать данные напрямую из DOM и Network.
3. Выполнять действия в браузере.
4. Автоматически использовать инструменты через Tool Calling.
5. Работать через Playwright + CDP.
6. Использовать скриншоты только по запросу пользователя.
7. Экспортировать данные в JSON, CSV и Markdown.
8. Поддерживать клонирование сайта в локальную директорию.
