# Kibborg — правила для агентов

## Паритет Telegram ↔ Web (обязательно)

**Всё, что добавляется для Telegram-агента, должно добавляться и для веб-версии — и наоборот.**

Интерфейсы разные (чат Telegram vs локальная панель `http://127.0.0.1:PORT_WEB`), но **возможности и инструменты** должны совпадать:

| Возможность | Telegram | Web |
|---|---|---|
| Чат с LLM | текст / голос | `/api/chat` |
| Картинки / vision | photo / document | multipart upload |
| `/chart` разбор графика | команда + скрин | картинка + `/chart` в подписи или сообщении |
| `/analyze` тикер | команда | вкладка Анализ + API |
| `/browser` Browser Agent | команда | вкладка Браузер + `/api/browser` + `/browser` в чате |
| `/download` видео (YouTube/Instagram/…) | команда или голая ссылка | вкладка Видео + `/api/download_video` + ссылка в чате |
| `/reset` | команда | кнопка Сброс |
| Артефакты (скрин/видео/файлы) | sendPhoto / sendVideo / путь | ссылки `/api/files/…` |

### Как соблюдать при новой фиче

1. Реализуй **общее ядро** (пакет `browser`, `trading`, общий helper) — без привязки к каналу.
2. Подключи **Telegram** (`main.go` / команды / `sendArtifacts`).
3. Подключи **Web** (`webui.go` API + `web/index.html` UI).
4. Обнови help (`/start`) и подсказки в UI.
5. Добавь/обнови тесты на обе стороны, если меняется контракт.

Не делай «только в Telegram, веб потом» и не делай «только кнопку на вебе без команды в боте».

## Browser Agent tools

Каталог инструментов живёт в `engine-go/browser/tools.go` (один набор для обоих каналов — browser agent один).
Новый tool → описание + `Dispatch` + упоминание в system prompt (`agent.go`) + при необходимости доставка артефакта.
